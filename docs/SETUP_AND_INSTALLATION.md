# Setup and Installation Guide

## 1. Overview

This document explains how to set up and run the **AI-Powered Customer Support Assistant with Live Response Guidance** in a local development environment.

The project uses Python and Flask for backend processing, HTML/CSS/JavaScript for the frontend, and Google Gemini for AI-assisted features.

---

## 2. Prerequisites

Before running the project, ensure the following software is installed:

- Python
- Git
- Visual Studio Code
- A modern web browser
- Internet connection for AI-based features
- Google Gemini API key for generative AI functionality
